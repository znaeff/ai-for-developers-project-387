# Docker-образ приложения

Приложение собирается в один multi-stage образ: build-стадия ставит Node 22 и pnpm через Corepack и выполняет `pnpm build`, финальная стадия содержит только собранный бэкенд и фронтенд. Запускается один Node-процесс: он отдаёт собранные файлы фронтенда и обрабатывает API на одном порту `PORT`.

Префикс `/api` нормализуется в `createServer()` только когда передана соответствующая опция: в dev-режиме Vite по-прежнему проксирует `/api` на бэкенд и снимает префикс, а тесты вызывают `createServer()` без опций и проверяют неизменное поведение `GET /reserve`.

Альтернативы — отдельные контейнеры для фронтенда и бэкенда или nginx внутри одного контейнера — отклонены: для учебного проекта важнее один образ, один порт и минимальное число движущихся частей. Внешний деплой и оркестрация остаются вне объёма работ.
