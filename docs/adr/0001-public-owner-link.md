# Публичная ссылка на страницу владельца

README описывает доступ владельца «по заранее определённому URL-у», но стартовая страница ведёт на `/owner` открыто. Мы решили сделать ссылку «Управление календарём» публичной и не вводить токены или авторизацию: это учебный проект, где важнее простая навигация между ролями, чем разделение доступа.

Альтернатива — секретный URL для владельца — отклонена: она добавляет управление секретом без учебной ценности в текущем объёме работ.
