# API contract

`main.tsp` — источник истины для HTTP API. Из него генерируются:

- `contracts/openapi/openapi.json` — OpenAPI 3.0;
- `apps/frontend/src/api/generated/**` — TypeScript SDK.

Обе генерации запускаются одной командой:

```bash
mise run generate
```

Сгенерированные файлы коммитятся. Не редактируйте их вручную: меняйте `main.tsp` и запускайте генерацию.

Серверный код намеренно не генерируется: бэкенд использует встроенный `node:http`, для которого в выбранном стеке нет подходящего генератора. Серверные обработчики поддерживаются вручную и проверяются contract-тестом и HTTP-тестами.
