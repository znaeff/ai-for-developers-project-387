# Календарь звонков

Учебное приложение для бронирования встреч: владелец управляет календарём, гость выбирает свободное время и бронирует встречу.

## Language

**Владелец**:
Администратор календаря, который создаёт типы встреч и просматривает встречи, забронированные гостями.
_Avoid_: Администратор

**Гость**:
Пользователь календаря, который бронирует встречу в свободный слот, указывая своё имя и почту.
_Avoid_: Пользователь, посетитель

**Тип встречи**:
Шаблон встречи, который создаёт Владелец: название, описание и длительность в минутах. Длительность уникальна: двух Типов с одинаковой длительностью быть не может. Гость выбирает Тип встречи при бронировании.
_Avoid_: Тип события, формат встречи

**Слот**:
Интервал времени, в который встреча выбранного Типа целиком помещается в рабочие часы Владельца. Слоты вычисляются из расписания и длительности, а не хранятся отдельно. У Владельца один календарь, поэтому Слоты общие для всех Типов встреч. Занятые Слоты остаются в выдаче с `isAvailable: false`.
_Avoid_: Таймслот, окно, ячейка календаря

**Бронь**:
Запись о встрече, которую Гость создаёт в свободном Слоте, указывая имя и почту. Бронь хранит Тип встречи, начало встречи и данные Гостя; занятые Брони делают недоступными Слоты, которые пересекаются с интервалом встречи, независимо от Типа встречи.
_Avoid_: Запись, резервация, резерв
